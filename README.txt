Ixxl Chat — Server Context Menu Update

Right-click a server icon in the far-left server rail to open its menu.
Owners can copy the invite code/server ID, open Server settings, upload a server image, and delete a server (except the built-in Ixxl Chat server). Non-owners only see the copy option.

The owner-only delete-server RPC migration is included and has already been applied to the connected Supabase project. Replace your existing HTML with liquid_glass_discord_chat.html.
